# 本地定制（custom/voice-ui 分支）

本分支在 **dsh-voice-mode 0.7.25 的运行产物（lib/）** 上做了语音交互定制。`lib/` 是插件实际加载的文件，
因此覆盖 `lib/client.js` 与 `lib/index.js` 即可直接安装使用。

## 定制内容

### 界面
- 语音状态条与字幕浮层取消，全部收进输入框右下角的麦克风按钮（`conversation.input.activity`）。
- 按钮固定 34×34，热区不变：
  - 聆听：绿色三根迷你均衡器，随麦克风音量跳动；
  - 朗读：蓝色五根均衡器，随播放音量跳动；
  - 等待回复：转圈；结束中：对勾；按住：红色；进入中：蓝色；均有圆形底色。
- 计时在按钮下方（绝对定位，不占热区），仅录音时计时。
- VAD 检测到说话：右上角橙点；出错：左上角红点（悬停看原因）。
- 朗读中点击按钮＝停止朗读并退出语音模式；非朗读时点击＝进入/退出。
- 点击与快捷键防抖均为 250ms；快捷键支持 `Opt/Cmd` 写法，光标在输入框内也生效。
- 右键按钮：交互模式（持续聆听 / 按住说话 / 说完就关）、朗读回复（语音模式 / 总是 / 关闭）、字幕浮层开关、自动发送。
- 布局固定为「全部收进麦克风按钮」；字幕浮层与「顶部状态条」各有一个开关（默认都关，右键或设置里打开）。状态条宽度与输入框一致。
- 语音识别中的半成品文字实时写入输入框，定稿后替换。

### 行为
- `readAloud`：`voice`（默认，仅语音模式）/ `always`（当前会话所有回复，含打字）/ `off`（从不）。
- `mode: once`：说一段 → 停录 → 等回复朗读完 → 自动退出。
- 实时音量反馈走 rAF 直改样式，不触发 React 重渲染。

### 宿主
- `POST /voice-mode/focus`：上报当前会话，`always` 模式只朗读该会话。
- TTS 队列滑动窗口预合成（Edge 并发 5），缩短句间空白。
- `/voice-mode/stream`：同 tabId 去重、上限 8、心跳写失败清理，修复连接占满导致朗读无声。

### 客户端
- `/voice-mode/stream` 改为窗口级单例，避免插件热更新造成连接堆积。
- 播放输出加 AnalyserNode，朗读音量实时反馈。

## 注意
- 本分支的 `lib/` 基于 **0.7.25**；`src/` 仍是上游 main 的新版源码。二者不同步。
- 如需从 `src/` 重新构建，需要先把上述改动移植到源码；否则 `node build.mjs` 会覆盖 `lib/`，定制失效。
- 安装：`pnpm add dsh-voice-mode@github:dyguests/dsh-voice-mode#custom/voice-ui`
